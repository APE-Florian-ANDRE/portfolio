Pacebook

Il marche sans connexion. Un compte retrouve ensuite les données sur tous les appareils.

BPM Pulse

Une application iPhone et Apple Watch qui cale Spotify sur le rythme de l'effort : quand le BPM s'écarte de plus de 8 % du tempo du morceau, la file d'attente se renouvelle.

Un bouton Boost lance tout de suite un titre plus rapide et plus énergique.

  • React Native
  • Expo
  • TypeScript
  • Swift
  • API Spotify
  • HealthKit

Ravito

Un suivi nutrition sur mesure : calories, protéines, fibres, eau, poids, recettes maison et objectifs personnalisables.

Parti d'une page autonome, il est devenu une vraie application avec comptes, API et base de données.

  • React
  • TypeScript
  • Express
  • PostgreSQL
  • Prisma
  • Docker

Dédale

Un mini-jeu 2D dessiné sur canvas : dix cartes à traverser au clavier, entre eau, buissons et lave.

Les collisions, les sprites et le passage d'une carte à l'autre sont écrits à la main, sans moteur de jeu.

  • TypeScript
  • Canvas
  • Vite
